# WireNest — PCB Harness Studio

하우징·PCB 배치와 배선(하네스) 계획을 위한 3D 에디터. Figma로 배선도를 그리는 수고를 대체하려고 만든 툴입니다.

빌드 없이 로컬 HTTP 서버로 실행합니다. Three.js와 STEP 변환기(occt-import-js)는 CDN에서 불러오므로 인터넷 연결이 필요합니다. 모델 파일은 브라우저 안에서 처리합니다.

## 실행

```bash
# 프로젝트 폴더에서 실행
python -m http.server 8000
# → http://localhost:8000
```

홈 화면의 **하우징 배선 예제**를 누르거나 `http://localhost:8000/?example=housing`을 열면 반투명 하우징 안의 PCB 두 개와 5V/GND/SDA/SCL 배선을 확인할 수 있습니다. `examples/`에는 원본 STL 세 개와 다시 열 수 있는 `housing-wiring.wnest`도 있습니다. 예제 형상은 시각화 설명용이며 제조 검증을 거친 설계가 아닙니다.

## 기능

- **STL / STEP 하우징·PCB 가져오기** — 파일 메뉴에서 역할을 선택해 `.stl`, `.step`, `.stp`를 가져옵니다. ASCII/바이너리 STL과 STEP 메시 변환을 지원합니다.
- **모델 기반 배선** — 위치·크기·평면 회전과 불투명도를 조절하고, `P`로 모델 표면에 연결점을 추가한 뒤 `W`로 연결합니다. 연결점은 모델 이동·평면 회전을 따라갑니다. 와이어 우클릭으로 경유점을 추가해 내부 경로를 조절합니다.
- **하우징 투명 표시** — 기본 불투명도 25%. 내부 PCB에 연결점을 찍을 때는 왼쪽 목록의 눈 아이콘으로 하우징을 잠시 숨깁니다. 형상과 연결점은 프로젝트 JSON에 함께 저장됩니다.

### 3D 모델 사용 범위

STL은 단위 정보가 없어 mm로 해석합니다. STEP은 mm로 변환합니다. 모델의 Z축을 높이로 사용하며, 각 모델의 바닥을 높이 0에 배치하므로 가져온 뒤 실제 조립 위치를 맞춰 주세요. 다른 방향으로 만들어진 모델은 CAD에서 Z-up으로 내보내세요. STEP 어셈블리는 하나의 배치 대상으로 가져오며 원본 색상과 부품별 편집은 보존하지 않습니다.

파일당 30MB, 변환 결과 20만 삼각형까지 지원합니다. 핀·네트 정보 추출, 자동 배선, 하우징 관통/간섭 판정은 포함하지 않습니다. 연결점과 경유점은 직접 지정합니다. STEP 변환은 [occt-import-js](https://github.com/kovacsv/occt-import-js)를 사용합니다.

### 기존 편집 기능

- **6면 패드 배치** — 앞면(Top·부품면) / 뒷면(Bottom·솔더면) / 상·하·좌·우 모서리. 터미널이 앞·뒤 어느 쪽에 붙는지 지정.
- **3D + 정사영 뷰** — 3D(빈 곳 좌드래그로 오빗) / Top / Front / Back / Left / Right / Bottom. 옆에서 보면 어느 면 터미널인지 한눈에 확인.
- **다중선택 · 복붙** — `Shift`+드래그 박스 선택 → `Ctrl+C`/`Ctrl+V` (보드·패드·내부 배선 통째). `Ctrl+D` 즉시복제.
- **네트(같은 선 묶음)** — 신호선별 색상, 이름 클릭 시 번들 하이라이트.
- **치수/전선 규격** — 보드 크기·두께·위치 mm 단위, 전선 AWG(12~30)별 굵기.
- **입력 토글 시뮬레이션** — 입력 패드 클릭 시 연결된 네트가 점등 전파.
- **이미지 오버레이** — 보드 앞면에 실제 PCB 이미지 업로드.
- **저장/열기(JSON)**, **PNG 내보내기**, 라이트/다크 테마, Undo/Redo.

## 단축키

| 키 | 동작 |
|---|---|
| `V` / `B` / `P` / `W` / `H` | 선택 / 보드 / 패드 / 배선 / 화면이동 |
| `1`~`7` | 3D / Top / Front / Left / Right / Back / Bottom 뷰 |
| `F` | 화면 맞춤 |
| `Shift`+드래그 | 보드 다중선택 |
| `Ctrl+C` / `V` / `D` / `A` | 복사 / 붙여넣기 / 복제 / 전체선택 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 실행취소 / 다시실행 |
| `Space`+드래그 | 화면 이동(팬) · 휠 = 줌 |

## 조작

- **3D 뷰**: 빈 곳 드래그 = 회전 · 보드 위 드래그 = 이동 · 휠 = 줌
- **2D 뷰**: 빈 곳 드래그 = 화면이동 · 보드 드래그 = 그 평면에서 이동(Front 뷰에서 드래그하면 X·Z 높이 조절)
- **패드 추가**(`P`)는 현재 보고 있는 면에 붙습니다 (Top뷰 → 앞면, Bottom뷰 → 뒷면 …)

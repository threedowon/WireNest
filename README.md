# WireNest — PCB Harness Studio

PCB 배치와 배선(하네스) 계획을 위한 브라우저 3D 에디터. Figma로 배선도를 그리는 수고를 대체하려고 만든 툴입니다.

의존성 없음(번들/빌드 없음) — **`index.html` 하나**가 전부입니다. 더블클릭으로 열면 됩니다. (Three.js는 CDN에서 불러오므로 인터넷 연결 필요)

## 실행

```bash
# 파일을 더블클릭하거나, 원하면 로컬 서버로 열기
python -m http.server 8000
# → http://localhost:8000
```

배포 시에도 `index.html`만 정적 호스팅하면 됩니다.

## 기능

- **6면 패드 배치** — 앞면(Top·부품면) / 뒷면(Bottom·솔더면). 터미널이 앞·뒤 어느 쪽에 붙는지 지정.
- **3D + 정사영 뷰** — 3D(빈 곳 좌드래그로 오빗) / Top / Front / Bottom.
- **다중선택 · 복붙** — `Shift`+드래그 박스 선택 → `Ctrl+C`/`Ctrl+V` · `Ctrl+D` 즉시복제.
- **네트(같은 선 묶음)** — 신호선별 색상, 이름 클릭 시 번들 하이라이트.
- **치수/전선 규격** — 보드·전선 AWG mm 단위.
- **입력 토글 시뮬레이션** — 패드 클릭 시 연결된 네트 점등 전파.
- **이미지 오버레이** — 보드 앞/뒷면 PCB 이미지.
- **3D 하우징** — 보드 AABB 기반 풀 엔클로저(바닥·벽·뚜껑·스탠드오프·케이블 출구).
- **CAD 익스포트** — 하우징 **SVG / DXF / STL** (Fusion·레이저·3D 프린트).
- **저장/열기(.wnest)**, **PNG**, 라이트/다크, Undo/Redo.

## 하우징 · Fusion 360

1. 보드를 배치한 뒤 오른쪽 인스펙터 **하우징**에서 **3D 미리보기**를 켭니다.
2. 여유·벽 두께·스탠드오프·케이블 출구를 조절합니다. **배선 기준 출구 제안**으로 경계를 넘는 배선에 슬롯을 자동 추가할 수 있습니다.
3. **파일 ▾ → 내보내기**에서 포맷 선택:
   - **하우징 SVG / DXF** — 면별 2D 프로필(mm). Fusion: *Insert → SVG/DXF* → 패널마다 *Extrude* (두께는 파일 라벨의 `t=` / 바닥·벽·뚜껑 설정값).
   - **하우징 STL** — 조립 미리보기 메시(프린트·형상 확인용). 정밀 조립은 SVG/DXF로 Extrude 후 Combine 권장.

STEP은 지원하지 않습니다. CAD에서 편집할 때는 SVG/DXF 프로필 → Extrude 워크플로를 쓰세요.

## 단축키

| 키 | 동작 |
|---|---|
| `V` / `B` / `P` / `W` / `T` | 선택 / 보드 / 패드 / 배선 / 텍스트 |
| `1`~`4` | 3D / Top / Front / Bottom 뷰 |
| `F` | 화면 맞춤 |
| `Shift`+드래그 | 다중선택 |
| `Ctrl+C` / `V` / `D` / `A` | 복사 / 붙여넣기 / 복제 / 전체선택 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 실행취소 / 다시실행 |
| `Space`+드래그 | 화면 이동(팬) · 휠 = 줌 |

## 조작

- **3D 뷰**: 빈 곳 드래그 = 회전 · 보드 위 드래그 = 이동 · 휠 = 줌
- **2D 뷰**: 빈 곳 드래그 = 화면이동 · 보드 드래그 = 그 평면에서 이동
- **패드 추가**(`P`)는 클릭한 보드 면에 붙습니다

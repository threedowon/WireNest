# WireNest — PCB Harness Studio

하우징·PCB 배치와 배선(하네스) 계획을 위한 3D 에디터. Figma로 배선도를 그리는 수고를 대체하려고 만든 툴입니다.

빌드 없이 로컬 HTTP 서버로 실행합니다. Three.js와 STEP 변환기(occt-import-js)는 CDN에서 불러오므로 인터넷 연결이 필요합니다. 모델 파일은 브라우저 안에서 처리합니다.

## 실행

Windows에서는 **`start.cmd`를 더블클릭**하면 빈 홈 화면으로 앱이 열립니다. [Python 3](https://www.python.org/downloads/)가 필요하며 설치 시 **Add Python to PATH**를 선택하세요. 실행 창은 사용하는 동안 열어 두고, 종료할 때 닫으면 됩니다. macOS/Linux에서는 `python3 launch.py`로 실행합니다. 서버는 이 PC에서만 접속할 수 있는 주소와 사용 가능한 포트를 자동으로 사용합니다.

`index.html`을 직접 더블클릭하는 방식은 지원하지 않습니다. 다음과 같이 직접 서버를 실행해도 됩니다.

```bash
# 프로젝트 폴더에서 실행
python -m http.server 8000
# → http://localhost:8000
```

홈 화면의 **하우징 배선 예제**를 누르거나 `http://localhost:8000/?example=housing`을 열면 반투명 하우징 안의 PCB 두 개와 5V/GND/SDA/SCL 배선을 확인할 수 있습니다. `examples/`에는 원본 STL 세 개와 다시 열 수 있는 `housing-wiring.wnest`도 있습니다. 예제 형상은 시각화 설명용이며 제조 검증을 거친 설계가 아닙니다.

## 다른 PC로 옮기기

1. 배포용 `WireNest.zip`을 다른 PC로 복사하고 **압축을 모두 풉니다**. 소스를 복사할 경우 `index.html`뿐 아니라 `model-import.js`, `ai-export.js`, `step-worker.js`, `examples/`, `launch.py`, `start.cmd`도 함께 옮깁니다.
2. Python 3를 설치하고 인터넷에 연결한 뒤 Windows는 `start.cmd`, macOS/Linux는 `python3 launch.py`로 실행합니다. Node.js나 npm 설치는 필요하지 않습니다.
3. 새 작업은 **파일 → 새 프로젝트 → 이름 입력 → 만들기**로 시작합니다. 새 프로젝트는 빈 작업 화면이며 보드는 B 도구 또는 모델 가져오기로 추가합니다.
4. 기존 작업은 원래 PC에서 **파일 → 저장**으로 `.wnest` 파일을 저장해 옮긴 다음, 새 PC의 **파일 → 열기**에서 선택합니다. 가져온 3D 형상은 `.wnest`에 포함됩니다. 자동 동기화나 자동 저장은 하지 않습니다.

`127.0.0.1` 주소는 실행 중인 PC 자신을 가리키므로 다른 PC로 링크만 보내서는 열리지 않습니다. 이 패키지는 Python 런타임을 포함한 독립 실행 EXE가 아니며, CDN 의존성 때문에 완전 오프라인 실행도 지원하지 않습니다.

## 기능

### KiCad 거버에서 패드 가져오기

**파일 → KiCad 거버 패드 가져오기 (ZIP)**에서 KiCad X2 거버 ZIP 또는 압축 해제한 `.gbr`·`.gbrjob` 파일들을 선택합니다. 앞/뒷면 동박과 `Edge_Cuts` 외곽 파일이 필요합니다. KiCad에서 **X2 형식 및 네트리스트 속성 포함**을 켜고, 모든 레이어를 같은 원점으로 출력하세요.

1. 기본으로 `J` 커넥터와 `TP` 테스트포인트의 앞면 패드를 선택합니다. 부품 검색·전체 선택·앞면/뒷면/양면 선택을 지원합니다. 양면을 고르면 같은 스루홀 핀도 양쪽 표면에 별도 연결점으로 생성됩니다.
2. **PCB STEP 파일 선택**에서 적용할 `.step`/`.stp`를 지정하거나 이미 가져온 PCB를 선택합니다. 별도의 사각형 PCB를 만들지 않고 지정한 모델에 연결점을 추가합니다. 새 STEP은 최종 적용할 때만 프로젝트에 추가되며, 취소하면 모델과 패드 모두 추가하지 않습니다.
3. 위에서 본 미리보기로 1:1 위치를 확인합니다. 90도 단위 회전, Y 반전, XY 이동, 앞/뒷면 높이를 조정할 수 있습니다. 높이는 대상 모델 바닥 기준입니다. STEP의 경계 상자에는 부품까지 포함될 수 있어 실제 PCB 원점과 동박 높이를 직접 확인해야 합니다. STEP 또는 기존 PCB에 적용하기 전에 방향·원점·표면 높이 확인 체크가 필요합니다.
4. 연결점 가져오기를 누릅니다. 부품명·핀·네트 속성이 `.wnest`와 AI 전달용 JSON에 저장됩니다. 같은 보드에 같은 원본 패드를 다시 가져오면 건너뜁니다. 수정된 거버로 기존 패드를 자동 갱신하지 않습니다. 가져오기는 한 번의 Undo로 되돌릴 수 있습니다.

AI 전달 파일의 `summary.pcbNets`는 보드 내부 CAD 네트 소속이며, 직접 그린 외부 하네스 배선과 구분됩니다. 같은 이름의 네트를 서로 다른 보드 사이에서 자동 연결하지 않습니다. 거버의 실제 동박 트랙 연결성이나 부품 내부 회로는 재구성하지 않습니다.

지원 범위: KiCad X2의 `.P` 핀 속성이 있는 ComponentPad/SMDPad 플래시 중심, 절대 좌표·선행 0 생략, mm/inch, 직선·다중 사분면 외곽 원호. 비아·일반 동박·마스크는 패드로 만들지 않습니다. 반복·좌표 변환·속성 없는 거버는 지원하지 않으며 안내 메시지를 표시합니다. ZIP은 25MB, 개별 거버는 10MB, 압축 해제 대상 전체는 40MB 이하입니다. 모든 파일은 브라우저 안에서 처리합니다.

소스를 옮길 때 `gerber-import.js`, `gerber-ui.js`, `gerber.css`도 함께 복사하세요. 자동 검증은 Node 24에서 `node --test tests/*.test.mjs`로 실행합니다. 선택적으로 `WIRENEST_GERBER_ZIP` 환경 변수에 로컬 ZIP 경로를 지정하면 실제 파일도 검사하며, 사용자 거버는 저장소나 배포 ZIP에 포함하지 않습니다.

### AI 전달용 내보내기

**파일 → 내보내기 → AI 전달용 파일**을 누르면 `<프로젝트명>_AI.json` 한 개를 내려받습니다. 다른 채팅에 이 파일을 첨부하면 WireNest 소스를 따로 설명하지 않아도 다음 정보를 읽을 수 있습니다.

- 파일 읽는 순서, 필드 설명, mm 단위와 좌표·회전·메시 변환 규칙
- 하우징·PCB의 크기, 배치, 회전, 실제 메시의 월드 경계, 삼각형 수
- 연결점의 이름·ID·월드 위치, 배선 양 끝, 네트·AWG·경유점
- 실제 와이어 기준 연결 그룹, 미연결 패드, 누락된 참조와 여러 네트가 만나는 연결의 검토 안내
- 원본 프로젝트 전체와 내장 3D 메시, 이미지, 메모 (숨긴 부품도 포함)

파일은 `readme`(설명), `summary`(계산한 요약), `project`(편집 원본) 구조입니다. WireNest의 **파일 → 열기**로 다시 열 수도 있습니다. 요약만 수정해도 원본 배치는 바뀌지 않습니다. 내보내기는 현재 작업의 스냅샷이며 기존 저장 파일이나 저장 여부를 변경하지 않고, 외부 서버나 AI 서비스에 자동 전송하지 않습니다. `.wnest` 백업은 기존 **저장** 기능을 사용하세요.

3D 형상은 수치 데이터로 포함되지만, 받는 AI가 파일·코드 실행 도구를 갖추어야 큰 메시를 분석하거나 재구성할 수 있습니다. STEP의 원래 CAD 곡면·설계 이력은 포함되지 않으며, 구멍 치수·벽 두께·간섭 여부·전기적 안전은 자동 검증하지 않습니다. 정밀한 CAD 수정에는 원본 STEP와 확인된 치수를 함께 제공하세요. 큰 형상이나 이미지가 있으면 AI 전달 파일도 커집니다.

- **STL / STEP 하우징·PCB 가져오기** — 파일 메뉴에서 역할을 선택해 `.stl`, `.step`, `.stp`를 가져옵니다. ASCII/바이너리 STL과 STEP 메시 변환을 지원합니다.
- **모델 기반 배선** — 위치·크기·평면 회전과 불투명도를 조절하고, `P`로 모델 표면에 연결점을 추가한 뒤 `W`로 연결합니다. 연결점은 모델 이동·평면 회전을 따라갑니다. 와이어 우클릭으로 경유점을 추가해 내부 경로를 조절합니다.
- **하우징 투명 표시** — 기본 불투명도 25%. 내부 PCB에 연결점을 찍을 때는 왼쪽 목록의 눈 아이콘으로 하우징을 잠시 숨깁니다. 형상과 연결점은 프로젝트 JSON에 함께 저장됩니다.

### 3D 모델 사용 범위

STL은 단위 정보가 없어 mm로 해석합니다. STEP은 mm로 변환합니다. 모델의 Z축을 높이로 사용하며, 각 모델의 바닥을 높이 0에 배치하므로 가져온 뒤 실제 조립 위치를 맞춰 주세요. 다른 방향으로 만들어진 모델은 CAD에서 Z-up으로 내보내세요. STEP 어셈블리는 하나의 배치 대상으로 가져오며 원본 색상과 부품별 편집은 보존하지 않습니다.

파일당 30MB, 변환 결과 20만 삼각형까지 지원합니다. 핀·네트 정보 추출, 자동 배선, 하우징 관통/간섭 판정은 포함하지 않습니다. 연결점과 경유점은 직접 지정합니다. STEP 변환은 [occt-import-js](https://github.com/kovacsv/occt-import-js)를 사용합니다.

### 기존 편집 기능

- **6면 패드 배치** — 앞면(Top·부품면) / 뒷면(Bottom·솔더면) / 상·하·좌·우 모서리. 터미널이 앞·뒤 어느 쪽에 붙는지 지정.
- **3D + 정사영 뷰** — 3D(빈 곳 좌드래그로 오빗) / Top / Front / Back / Left / Right / Bottom. 옆에서 보면 어느 면 터미널인지 한눈에 확인.
- **다중선택 · 복붙** — `Shift`+드래그 박스 선택 → `Ctrl+C`/`Ctrl+V` (보드·패드·내부 배선 통째). `Ctrl+D` 즉시복제.
- **네트(같은 선 묶음)** — 신호선별 색상, 이름 클릭 시 번들 하이라이트.
- **치수/전선 규격** — 보드 크기·두께·위치 mm 단위, 전선 AWG(12~30)별 굵기.
- **입력 토글 시뮬레이션** — 입력 패드 클릭 시 연결된 네트가 점등 전파.
- **이미지 오버레이** — 보드 앞면에 실제 PCB 이미지 업로드.
- **저장/열기(JSON)**, **PNG 내보내기**, 라이트/다크 테마, Undo/Redo.

## 단축키

| 키 | 동작 |
|---|---|
| `V` / `B` / `P` / `W` / `H` | 선택 / 보드 / 패드 / 배선 / 화면이동 |
| `1`~`7` | 3D / Top / Front / Left / Right / Back / Bottom 뷰 |
| `F` | 화면 맞춤 |
| `Shift`+드래그 | 보드 다중선택 |
| `Ctrl+C` / `V` / `D` / `A` | 복사 / 붙여넣기 / 복제 / 전체선택 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 실행취소 / 다시실행 |
| `Space`+드래그 | 화면 이동(팬) · 휠 = 줌 |

## 조작

- **3D 뷰**: 빈 곳 드래그 = 회전 · 보드 위 드래그 = 이동 · 휠 = 줌
- **2D 뷰**: 빈 곳 드래그 = 화면이동 · 보드 드래그 = 그 평면에서 이동(Front 뷰에서 드래그하면 X·Z 높이 조절)
- **패드 추가**(`P`)는 현재 보고 있는 면에 붙습니다 (Top뷰 → 앞면, Bottom뷰 → 뒷면 …)

### 거버 실크스크린 표시

- 거버 가져오기에서 연결점 주변 8mm / 선택한 면 전체 / 가져오지 않음을 선택합니다.
- 실크는 원본 선·원호·단일 윤곽 채움 도형으로 표시하며, 글자를 핀 이름으로 자동 해석하지 않습니다. 다중 윤곽 채움, 반전, 플래시 실크는 지원하지 않습니다.
- 실크를 가져오면 자동 부품·핀 번호 라벨을 숨깁니다. 보드 설정의 패드 이름 / 실크스크린으로 표시를 전환합니다. 원래 핀·네트 정보는 유지됩니다.
- 실크 자체에 인쇄된 부품 번호는 원본 도형에 포함됩니다. 주변 범위 경계에서는 일부 도형만 포함될 수 있어 전체 면 옵션으로 확인할 수 있습니다.

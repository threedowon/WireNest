# WireNest — PCB Harness Studio

PCB 배치와 배선(하네스) 계획을 위한 단일 파일 3D 에디터. Figma로 배선도를 그리는 수고를 대체하려고 만든 툴입니다.

의존성 없음 — `index.html` 하나가 전부입니다. 브라우저에서 바로 열면 됩니다.

## 실행

```bash
# 그냥 파일을 더블클릭하거나, 로컬 서버로 열기
python -m http.server 8000
# → http://localhost:8000
```

## 기능

- **6면 패드 배치** — 앞면(Top·부품면) / 뒷면(Bottom·솔더면) / 상·하·좌·우 모서리. 터미널이 앞·뒤 어느 쪽에 붙는지 지정.
- **3D + 정사영 뷰** — 3D(빈 곳 좌드래그로 오빗) / Top / Front / Back / Left / Right / Bottom. 옆에서 보면 어느 면 터미널인지 한눈에 확인.
- **다중선택 · 복붙** — `Shift`+드래그 박스 선택 → `Ctrl+C`/`Ctrl+V` (보드·패드·내부 배선 통째). `Ctrl+D` 즉시복제.
- **네트(같은 선 묶음)** — 신호선별 색상, 이름 클릭 시 번들 하이라이트.
- **치수/전선 규격** — 보드 크기·두께·위치 mm 단위, 전선 AWG(12~30)별 굵기.
- **입력 토글 시뮬레이션** — 입력 패드 클릭 시 연결된 네트가 점등 전파.
- **이미지 오버레이** — 보드 앞면에 실제 PCB 이미지 업로드.
- **저장/열기(JSON)**, **PNG 내보내기**, 라이트/다크 테마, Undo/Redo.

## 단축키

| 키 | 동작 |
|---|---|
| `V` / `B` / `P` / `W` / `H` | 선택 / 보드 / 패드 / 배선 / 화면이동 |
| `1`~`7` | 3D / Top / Front / Left / Right / Back / Bottom 뷰 |
| `F` | 화면 맞춤 |
| `Shift`+드래그 | 보드 다중선택 |
| `Ctrl+C` / `V` / `D` / `A` | 복사 / 붙여넣기 / 복제 / 전체선택 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 실행취소 / 다시실행 |
| `Space`+드래그 | 화면 이동(팬) · 휠 = 줌 |

## 조작

- **3D 뷰**: 빈 곳 드래그 = 회전 · 보드 위 드래그 = 이동 · 휠 = 줌
- **2D 뷰**: 빈 곳 드래그 = 화면이동 · 보드 드래그 = 그 평면에서 이동(Front 뷰에서 드래그하면 X·Z 높이 조절)
- **패드 추가**(`P`)는 현재 보고 있는 면에 붙습니다 (Top뷰 → 앞면, Bottom뷰 → 뒷면 …)
